Cascading Style Sheets (CSS)


Definisi

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan halaman web. Dengan CSS, kita dapat mengubah warna, ukuran tulisan, tata letak, dan banyak aspek visual lainnya. Latihan ini bertujuan agar Anda dapat memahami perbedaan antara CSS internal dan inline.

Penulisan CSS

  • Inline Style
  • Internal Style
  • Eksternal Style
